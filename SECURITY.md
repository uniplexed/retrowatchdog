# Security

RetroWatchdog is a personal, self-hosted application. Please report a
security problem privately through GitHub's **Report a vulnerability** button
on this repository (Security tab), not as a public issue. Include the version
or commit, what you did and what happened. You will get an answer within a
week, and a fix or a documented limitation as soon as it is ready.

Only the latest release is supported. Legal questions and take-down requests
are not security reports: open an issue, or see [LEGAL.md](LEGAL.md).
